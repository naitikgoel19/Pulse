About PalettePop

A calm, minimal color palette studio built for websites, UI designs, posters, and presentations.

What PalettePop Does

PalettePop helps students, designers, and developers create, customize, preview, and save balanced color combinations. Whether you are starting from a random palette, browsing curated themes, or extracting colors from an inspiration photo, everything works cleanly in one place.

How to Use PalettePop in 3 Simple Steps

1. Discover or Generate

Use Generate to create random 5-color palettes (and lock shades you like), Explore to browse curated categories, or Extract to pull colors from an image.

2. Customize & Preview

Open any palette in the Editor to adjust HEX codes, pick new shades, or add and remove colors (from 2 up to 8) with a live preview.

3. Copy, Save & Export

Copy individual HEX codes or full palettes with one click, export them as JSON, or save favorites to My Saved Palettes for future sessions.

Technologies Used

Frontend

Built with semantic HTML5, responsive CSS3, and Vanilla JavaScript — including the HTML5 Canvas API for local image color extraction and localStorage for saving personal palettes.

Backend & Storage

Powered by Node.js and Express.js to serve static pages and provide a lightweight REST API backed by a local JSON file (data/palettes.json), with no external APIs or databases required.
